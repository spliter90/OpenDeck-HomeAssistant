Home Assistant
Home Assistant → Benutzerprofil → Long-Lived Access Tokens. Der Token wird nicht ins Plugin-Log geschrieben.
Bei „Automatisch“ wird z. B. für light.* die Glühbirne verwendet.
Leer = normaler Entity-State. Beispiel: current_temperature, brightness, battery_level.
Home Assistant überspringt beim manuellen Trigger standardmäßig die Bedingungen. Ausschalten = Bedingungen vorher prüfen.
Beispiel: {"entity_id":"light.wohnzimmer","brightness_pct":35}.
Licht- und Entity-Status kommen live über /api/websocket. Szenen, Scripts/Routinen und Automationen werden direkt über Home Assistant ausgelöst.
